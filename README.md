# Kanban-трекер задач

MVP однопользовательского Kanban-трекера в стиле Linear: React + TypeScript + Vite + Tailwind CSS,
drag-and-drop на @dnd-kit, хранение данных в localStorage.

## Запуск

```bash
npm install     # установка зависимостей
npm run dev     # dev-сервер: http://localhost:5173
```

Дополнительные команды:

```bash
npm run build       # проверка типов + production-сборка в dist/
npm run preview     # локальный просмотр собранной версии
npm run typecheck   # проверка типов без сборки
npm run lint        # статический анализ (oxlint)
```

Требуется Node.js 20+ (проверено на Node 22).

## Что реализовано на текущем этапе

- Доска из четырёх фиксированных колонок: «Новая», «В работе», «На проверке», «Готово».
- Карточка задачи: название, бейдж приоритета с иконкой и текстовой подписью, аватар исполнителя
  (кружок с инициалами), теги, срок выполнения (просроченные подсвечиваются красным).
- Drag-and-drop:
  - перетаскивание между колонками (меняет статус задачи);
  - перетаскивание внутри колонки (меняет порядок);
  - тень и полупрозрачный оригинал при перетаскивании, плавающая копия (DragOverlay);
  - подсветка целевой колонки и пунктирная заглушка места вставки;
  - мышь, сенсор (долгое нажатие) и клавиатура (Space — взять, стрелки — переместить, Escape — отмена);
  - автопрокрутка колонок и доски средствами @dnd-kit.
- Модальное окно задачи (создание и редактирование):
  - поля: название (обязательное), описание, приоритет, исполнитель, срок, теги;
  - теги добавляются через запятую или Enter, удаляются кнопкой «×» или Backspace;
  - валидация названия (после trim не может быть пустым), ошибка под полем;
  - фокус при открытии — на поле «Название», возврат фокуса на открывший элемент;
  - закрытие по Esc и клику вне окна, удержание фокуса внутри (Tab), блокировка прокрутки страницы;
  - новая задача появляется в начале колонки «Новая».
- Удаление задачи через отдельный диалог подтверждения («Удалить задачу?» / «Да, удалить» /
  «Отмена»). Пока диалог открыт, модальное окно задачи закрыть нельзя.
- Поиск и фильтры в верхней панели:
  - поиск по названию и описанию без учёта регистра;
  - фильтр по исполнителю и по приоритету, тумблер «Скрывать выполненные», кнопка «Сбросить фильтры»;
  - фильтры работают одновременно (AND), счётчики колонок показывают отфильтрованное количество;
  - при активных фильтрах перетаскивание отключается, чтобы не ломать порядок скрытых задач
    (карточки становятся кликабельными, но не перетаскиваются, в панели фильтров — пояснение).
- Сохранение данных в localStorage (`kanban-board-data`) с автосохранением после каждого изменения.
- Демо-данные: 6 задач с разными приоритетами, исполнителями, тегами и сроками.
- Светлая и тёмная темы: переключатель в верхней панели, выбор сохраняется в `settings.theme`,
  класс `.dark` на `<html>`, все компоненты стилизованы под обе темы.
- Меню настроек (⋯): переключатель темы, экспорт в JSON, импорт из JSON.
- Экспорт: файл `kanban-board-YYYY-MM-DD.json` со всей структурой `BoardData` (версия, задачи,
  исполнители, настройки), все задачи включая отфильтрованные и завершённые.
- Импорт: валидация JSON, версии схемы, обязательных полей, уникальности ID, статусов/приоритетов,
  дат, ссылок на исполнителей; подтверждение замены текущих данных; при ошибке данные не меняются.

## Ключевые решения

**Данные.** Задачи хранятся плоским массивом; колонка определяется полем `status`, порядок внутри
колонки — полем `position`. Любая операция пересчитывает `position` и приводит массив к порядку
«колонка → позиция», поэтому порядок устойчив после перезагрузки. Создание, редактирование и
удаление идут через операции `useBoard`, которые обновляют состояние иммутабельно и сразу
сохраняют его в localStorage. Экспорт/импорт работают с полным объектом `BoardData`.

**Перетаскивание.** Данные не меняются до отпускания карточки: во время перетаскивания
показываются только визуальные эффекты (полупрозрачный оригинал, DragOverlay, подсветка колонки,
заглушка места вставки). Изменение применяется в `onDragEnd` одной операцией
(`moveTask` в `lib/taskUtils.ts`), которая заодно обновляет статус и правила `completedAt`:
при переходе в «Готово» дата завершения проставляется, при выходе — очищается, при перемещении
внутри «Готово» не меняется. При активных фильтрах перетаскивание отключается полностью —
это самый простой и надёжный способ не ломать порядок скрытых карточек.

**Перетаскивание.** Данные не меняются до отпускания карточки: во время перетаскивания
показываются только визуальные эффекты (полупрозрачный оригинал, DragOverlay, подсветка колонки,

**Сенсоры.** `MouseSensor` с порогом 5 px (клик не превращается в перетаскивание), `TouchSensor`
с задержкой 180 мс и допуском 8 px (обычный свайп остаётся скроллом, перетаскивание начинается
долгим нажатием), `KeyboardSensor` для доступности. У карточек не отключается `touch-action`,
чтобы сохранить вертикальную прокрутку колонок и горизонтальную прокрутку доски.

**Модальные окна.** Базовый `Modal` — портал, затемнённый фон, Esc и клик по фону, блокировка
прокрутки страницы, удержание фокуса внутри панели (Tab) и возврат фокуса на открывший элемент.
Пока открыт диалог подтверждения удаления, модальное окно задачи не закрывается ни одним из
способов — это исключает «осиротевший» диалог.

**Тема.** Светлая тема по умолчанию. Переключатель добавляет/убирает класс `.dark` на `<html>`,
выбор сохраняется в `settings.theme` и применяется при старте приложения.

**Импорт/экспорт.** Экспорт скачивает читаемый JSON с версией схемы. Импорт строго валидирует
структуру, типы, даты, уникальность ID, допустимые статусы/приоритеты и ссылки на исполнителей;
порядок карточек нормализуется через `reindexTasks`. При ошибке текущие данные не изменяются,
перед заменой запрашивается подтверждение.
